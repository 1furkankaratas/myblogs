# myblogs

[Auto Blog Writer](https://github.com/1furkankaratas) tarafından otomatik üretilen
ve insan onayından geçen blog yazıları.

Yapı: `content/posts/<yazi-slug>/` → `index.md` (front-matter'lı Markdown) +
`cover.png` (kapak) + `inline-N.png` (yazı içi görseller).

Hugo / Astro / Jekyll gibi statik site üreteçleriyle doğrudan kullanılabilir.
